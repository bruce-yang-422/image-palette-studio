## 新版本發布後

1. 使用儲存庫 Settings → Pages → GitHub Actions，執行 `.github/workflows/pages.yml`；確認測試與部署工作均成功。
2. 在實際 `/image-palette-studio/` 網址開啟新工作階段。檢查 HTML、CSS、JS、manifest、圖示及 `js/locales.js` 均無 404，並確認頂部有七語系選單。
3. 上傳、拖放與貼上測試圖片；切換所有色數，拖曳錨點、切換平均取樣與邊緣吸附、鎖定後重新生成。確認來源色不被風格改色。
4. 在生成模式設定主色、鎖定、切換 Oklch 風格與 60-30-10 配置；確認固定色碼及模式工作狀態保留。
5. 切換七語系、重新開啟及另開分頁，檢查文字與偏好同步。改變介面語言不應改寫主色輸入或自訂引線文字。
6. 遍歷七款版型、裁切／留白、HEX／RGB、內部／下方／關閉文字；匯出 PNG／JPG 三種倍率與 SVG，比對預覽構圖及像素尺寸。下載 ASE、ACO、JSON、CSS、Tailwind v3／v4，確認檔案可讀。
7. 等待可離線提示，斷網後重新開啟／重新載入。確認語言切換、載入本機圖片、生成與匯出可用；清除站點資料後的首次離線開啟不在承諾範圍內。
8. 保留舊版本工作中的分頁，再發布新版。確認快取完成顯示更新提示，且不強制重載；關閉所有本站分頁／安裝視窗再開啟應使用新版。
