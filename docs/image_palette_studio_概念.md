# 專案需求與規格書：Image Palette Studio 圖片色票工作室

## 1. 專案概述 (Overview)
**Image Palette Studio（圖片色票工作室）** 是一款開源、純前端、無伺服器架構的跨平台色彩工作站（PWA）。本專案旨在打破市面上主流色彩工具（如 Coolors、Adobe Capture、Pantone Connect）的付費壁壘，提供自由度極高的「照片萃取」與「無圖憑空生成」雙軌工作流，並具備專業電影劇照色票卡合成輸出能力。

---

## 2. 核心架構原則 (Core Principles & Constraints)
* **完全零 AI / 零神經網路模型**：全數基於確定性色彩學幾何公式、感知均勻色彩空間（Oklch / HSL）與數學約束進行計算。
* **純客戶端離線運作 (Zero Server Cost)**：所有像素讀取、色差運算與畫布渲染皆於瀏覽器端完成，保護照片隱私且享有毫秒級響應速度。
* **單一代碼庫跨平台 (Single Codebase PWA)**：採用靜態 Web 技術建置，支援桌機（PC / Mac）瀏覽器即開即用，以及 Android 手機透過 PWA 離線安裝至桌面，免去維護雙端原生專案的維護成本。

### 2.1 重點硬性要求：僅使用 GitHub Pages 即可完成部署

**GitHub Pages 必須足以部署並執行本專案全部核心功能。此為強制架構與驗收條件，優先於第 8 節的建議技術選型。**

* **純靜態部署**：發布內容必須為 HTML、CSS、JavaScript、圖片及其他靜態資源。允許在本機或 GitHub Actions 執行建置，但建置產物發布後，不得需要持續運行的伺服器程序。
* **不依賴後端**：圖片載入與處理、色彩提取、配色生成、畫布合成、色盲預覽及檔案匯出，必須在瀏覽器端完成；不得以自架 API、SSR、Serverless Functions、外部資料庫或付費服務作為核心功能的必要條件，也不得要求使用者提供 API Key。
* **支援儲存庫子路徑**：必須可部署於 GitHub Pages 的 `/image-palette-studio/` 路徑。資源引用、頁面連結，以及未來的 PWA manifest、Service Worker 路徑與作用範圍，都必須配合部署基底路徑，不得假設網站位於網域根目錄。
* **部署流程可重現**：文件須提供完整發布步驟；若使用建置工具，須提供對應的 GitHub Actions 建置與 Pages 發布設定。完成 GitHub Pages 設定後，不得要求另行部署其他平台或服務。
* **外部資源與離線能力**：外部字型或其他非必要資源載入失敗時，核心功能仍須可用。PWA 離線功能也必須在相同靜態部署下實現，必要資源須可由本站提供與快取。
* **部署驗收**：以實際 GitHub Pages 網址驗證頁面與資源載入、圖片上傳／拖放、配色生成、畫布預覽及各項匯出；已實作的其他核心功能亦須逐項確認。不得只以本機可執行或原始碼已上傳 GitHub 視為部署完成。

## 3. 雙軌工作模式 (Dual Workflow Modes)

### 模式 A：圖片劇照提取模式 (Image Extraction Mode)
* **多渠道輸入**：支援本機檔案上傳、拖曳圖片（Drag & Drop）與剪貼簿直接貼上（Paste）。
* **動態色槽數量**：支援自選抽取 3 色、4 色、5 色、6 色或 8 色。
* **智慧色彩過濾 (Diversity Filtering)**：
  * 使用中位數切割演算法（Median Cut）或 K-means 建立原始候選色彩池。
  * 透過 $\Delta E$ 色差計算自動剔除過度接近的色塊。
  * 智慧挑選並優先保留：亮部（Highlight）、暗部（Shadow）、高飽和主色（Vibrant）與過渡中性色。
* **手動選色工具 (Manual Picker Tools)**：
  * **可拖曳取色錨點 (Draggable Sample Pins)**：參考 Adobe Color「從圖片建立主題」的互動模式——依照當前設定的色票數量（如 5 色），系統自動在照片上放置對應數量的圓形取色錨點（初始位置為 K-means 自動判定的代表色所在座標）。每個錨點即時顯示其所在像素的顏色與 HEX 值，並與右側對應色槽一一對應（同色序、同編號）。
  * **拖曳即時取色**：使用者可直接以滑鼠或觸控拖曳任一錨點至照片上的其他位置，錨點移動時即時取樣該處像素色彩，並同步更新對應色槽與色票卡預覽；放開即完成取色，無需額外「確認」步驟。
  * **錨點吸附與微調**：拖曳時錨點中心點下方即時顯示放大鏡預覽（Magnifier Loupe），輔助精準定位單一像素；靠近邊緣時提供小範圍平均色（3×3 或 5×5 像素平均）以避免雜訊干擾。
  * **輔助滴管 (Eyedropper Fallback)**：電腦端仍可呼叫原生 `window.EyeDropper` API 進行跨視窗吸色，取色後直接覆蓋「目前選取中」的錨點位置；適合需要吸取瀏覽器視窗外顏色的情境。
  * **新增／移除錨點**：色票數量變更時，錨點數量同步增減（新增錨點預設落在尚未被佔用的高權重色彩區域；移除則對應刪除該色槽）。

### 模式 B：憑空生成模式 (From Scratch Mode)
* **全域快速隨機 (Spacebar Roll)**：
  * 開啟即依據當前風格預設自動產出調和色票。
  * 電腦端按空白鍵（Space）、手機端點擊浮動按鈕即時隨機替換未鎖定格子。
* **自由錨定鎖定 (Lock System)**：
  * 支援鎖定 1 到數個格子；隨機替換時，已鎖定的格子保持完全不變。
* **手動指定主色 (Manual Input)**：
  * 支援輸入 HEX / RGB / HSL 色碼或透過調色盤指定品牌主色。
  * 系統自動以指定色為核心，透過經典調和演算法補齊其餘未鎖定槽位。

## 4. 核心色彩運算管線 (Pipeline Architecture)

所有色彩運算依序通過以下管線處理：

```
                    ┌─ Chaos
                    │
Base Palette ───────┼─ Harmony
                    │
                    └─ Image Extraction
                            │
                            ▼
                     Style Projection
                            │
                            ▼
                    Locked Color Merge
                            │
                            ▼
                     Gamut / Safety Clamp
                            │
                            ▼
                       Final Palette
                            │
             ┌──────────────┼──────────────┐
             ▼              ▼              ▼
          Canvas         Gradient        Export
      (劇照色票合成)   (CSS 漸層生成)  (多格式檔案匯出)
```       

### 4.1 基礎調和策略 (Base Palette Generation)
* **類比色 (Analogous)**：色相偏移 $\pm 20^\circ \sim 40^\circ$。
* **互補色 (Complementary)**：色相對角線 $180^\circ$。
* **分裂互補 (Split-Complementary)**：色相對角線兩側 $150^\circ$ 與 $210^\circ$。
* **三角色 (Triadic)**：色相環等距 $120^\circ$ 分佈。
* **單色調 (Monochromatic)**：鎖定色相，依據明度階梯等距展開。
* **60-30-10 分配原則**：槽位強制承擔「主底色（低飽和高/低明度）」、「次要調和色」、「過渡中性色」與「高飽和點睛色」。

### 4.2 風格投影引擎 (Style Projection Profiles)
系統將色彩轉化為感知均勻空間，透過強制邊界夾取（Bounding Clamp）實現風格化：

| 風格名稱 | 色相約束 (Hue) | 飽和度約束 (Chroma / Sat) | 明度約束 (Lightness) |
| :--- | :--- | :--- | :--- |
| **莫蘭迪色 (Morandi)** | 全色相 | 極低飽和度 ($10\% \sim 28\%$) | 中高明度 ($45\% \sim 75\%$) |
| **馬卡龍色 (Macaron)** | 全色相 | 中低飽和度 ($40\% \sim 65\%$) | 極高明度 ($80\% \sim 95\%$) |
| **大地色系 (Earth Tone)** | $20^\circ \sim 55^\circ$ (赭石/泥土) | 中飽和度 ($25\% \sim 55\%$) | 中低明度 ($30\% \sim 65\%$) |
| **美拉德色 (Maillard)** | $15^\circ \sim 40^\circ$ (焦糖/深褐) | 中高飽和度 ($40\% \sim 75\%$) | 高對比明暗階梯 ($15\% \sim 75\%$) |
| **多巴胺色 (Dopamine)** | 全色相 | 極高飽和度 ($80\% \sim 100\%$) | 中高明度 ($55\% \sim 80\%$) |
| **薄荷曼波 (Mint Mambo)** | $140^\circ \sim 175^\circ$ (主色綠) | 中飽和度 ($40\% \sim 70\%$) | 高明度 ($65\% \sim 90\%$) |
| **波普色 (Pop Art)** | 三原色與高對比補色 | 純飽和度 ($90\% \sim 100\%$) | 極致對比度 |
| **森林自然系 (Biophilic)** | $75^\circ \sim 155^\circ$ (苔蘚/鼠尾草) | 低至中飽和度 ($20\% \sim 50\%$) | 搭配樹皮棕與晨霧灰 |
| **海洋系 (Coastal)** | $180^\circ \sim 230^\circ$ (海水藍/深海靛) | 中飽和度 ($30\% \sim 65\%$) | 搭配亞麻裸沙色 |
| **礦石地質系 (Mineral)** | $15^\circ \sim 25^\circ$ 赤陶土 | 低飽和度 ($10\% \sim 35\%$) | 搭配板岩冷灰與玄武岩深灰 |

## 5. 劇照色票卡排版與合成引擎 (Canvas Composition)

### 5.1 畫布比例控制

* **比例定義說明**：此處比例指「照片＋色票合成後之完整輸出畫布」比例，而非原始照片本身的裁切比例；照片區與色票區為合成疊加關係，色票為外加於照片之上（或下方延伸），非從照片內裁切扣除。
* **支援輸出比例**：`原始比例`、`1:1`（社群方形）、`4:3`、`3:2`、`16:9`、`2:1`（電影變形寬銀幕）、`9:16`（手機直式）。
* **版面自適應**：可切換「置中裁切（Center Crop）」或「保持完整＋留白裝裱（Letterbox）」，套用於畫布中的照片區塊。

### 5.2 版型縮圖庫與色票佔比 (Layout Thumbnail Gallery & Swatch Ratio)

參考 Canva 拼貼／版型選擇器的作法：版型並非僅以百分比數字呈現，而是提供**可視化縮圖網格**供使用者直接點選——每個縮圖以簡化色塊直接畫出「照片區＋色票區」實際的排列結果（形狀、位置、色票數量分布一目了然），點選後即套用到畫布並即時預覽。

* **版型縮圖選擇器**：
  * 以網格形式陳列所有版型縮圖（類似 Canva 版型面板），每個縮圖為 40×30px 等比例小圖示，用簡化矩形示意照片區（灰色/圖片縮圖）與色票區（彩色色塊）的相對位置與大小。
  * 縮圖庫可依「色票數量」（3／4／5／6／8 色）篩選，只顯示對應色票數的版型，避免選到色塊數量對不上的版型。
  * 選中的版型套用邊框高亮，滑鼠懸停顯示版型名稱與色票佔比預覽。
* **版型分類（依色票區位置與構成）**：
  * **底部通欄 (Bottom Strip)**：色票以等寬色塊一整排置於照片下方，為最常見的劇照色票卡樣式。
  * **側邊直條 (Side Bar)**：色票以直條色塊置於照片左側或右側，適合直式（9:16）構圖。
  * **四角散佈 (Corner Dots)**：色票以圓形色塊散佈於照片四角或邊緣，模擬 Pinterest 風格的 moodboard 圓點色卡。
  * **標籤引線 (Labeled Callout)**：色票搭配手寫風格文字標籤與指向線，標示照片中對應的色彩來源（如「Earth-tones」「Green Accents」等說明文字），仿手作 moodboard 拼貼風格。
  * **並排色條 (Adjacent Column)**：照片與整排色票並列於畫布左右兩側，各佔約一半寬度（對應截圖中「臥室照片＋右側直條色票」的常見 Pinterest 排版）。
  * **色票主導 (Swatch-Dominant)**：色票區塊佔比明顯大於照片區，色票本身即為視覺主體，照片縮小置於一角或省略。
* **色票佔比微調**：選定版型後，仍可用滑桿微調色票區佔畫布的比例（範圍依版型類別有各自合理區間，如底部通欄 8%～40%、並排色條 30%～60%），滑桿變更即時反映在畫布預覽，不影響已選版型的整體構圖邏輯。

### 5.3 渲染與視覺自訂

* **色塊排版**：色票區內等寬拼接 3～8 個色塊，支援調整間隙（Gap: 0～16px）與圓角（Radius: 0～12px）。
* **標籤資訊展示**：可選擇顯示 HEX、RGB 或關閉文字，文字色彩依據背景相對亮度（Luminance）自動翻轉為黑或白。

## 6. 無障礙與專業級匯出規格 (A11y & Exports)

### 6.1 無障礙檢測 (Accessibility)
* **WCAG 2.1 對比度**：即時分析每個色塊與標籤文字的對比值，標注 AA / AAA 合規標籤。
* **色盲模擬器 (Color Blindness Filter)**：透過 SVG 矩陣濾鏡即時預覽紅綠色盲（Protanopia/Deuteranopia）、藍黃色盲（Tritanopia）與全色盲視覺效果。

### 6.2 多格式匯出 (Pro Export Suite)
* **圖像格式**：透過 HTML5 Canvas 離屏渲染匯出高解析度無損 PNG / JPG。
* **向量格式**：產生完整 SVG 色票卡結構，方便直接拖入 Figma / Illustrator。
* **專業色票檔**：直接由二進位生成 `.ase`（Adobe Swatch Exchange）檔案，供 Photoshop / InDesign 直接匯入。
* **程式碼與樣式**：一鍵複製 CSS 變數（`:root`）、Tailwind 配色設定物件、W3C Design Tokens JSON。
* **漸層工具**：生成連續色票平滑 CSS Linear / Radial Gradient 語法。

## 7. 介面設定：主題與多語系 (UI Preferences: Theme & i18n)

### 7.1 顯示風格 (Display Theme)

* **亮色系 (Light)**：預設明亮介面。
* **暗色系 (Dark)**：低亮度深色介面，降低長時間使用之視覺疲勞。
* **跟隨系統 (Auto / System)**：依據作業系統 `prefers-color-scheme` 設定即時切換，並於系統主題變更時自動同步。

### 7.2 介面語言 (Language Support)

支援以下語系介面文字（可於設定中即時切換，並記憶使用者偏好）：

* 繁體中文（zh-TW）
* 英文（en）
* 日文（ja）
* 韓文（ko）
* 泰文（th）
* 越南文（vi）
* 西班牙文（es）

## 8. 建議技術棧與工具庫

* **核心框架**：Vue 3 或 React + Vite（輕量、高響應度）。
* **樣式排版**：Tailwind CSS（快速響應式排版）。
* **色彩數學庫**：
  * `colord`（搭配 `harmonies` 與 `a11y` 外掛）：處理色空間轉換、和諧運算與對比度。
  * 原生 CSS / 數學函式處理 Oklch 空間映射。
* **圖像提取庫**：`colorthief`（輕量中位數切割演算法）。
* **二進位生成庫**：`ase-utils`（匯出 `.ase` 專用）。
* **PWA 與部署**：`vite-plugin-pwa` + GitHub Pages（搭配 GitHub Actions 自動建置發布）。
